## What's included

<CardGrid>
  <Card title="Authentication" icon="seti:lock">
    Short-lived JWTs with rotating refresh tokens and reuse detection, Bearer header or HttpOnly cookies,
    remember-me, real logout, a session list users can end devices from, and every session ended on a password or
    role change.
  </Card>
  <Card title="Two-factor and social login" icon="approve-check-circle">
    Authenticator-app codes (TOTP) with encrypted secrets and single-use recovery codes, and login with GitHub and
    Google through a PKCE redirect that keeps the API stateless. Each provider turns on when its credentials are set.
  </Card>
  <Card title="Account flows" icon="email">
    Email verification and password reset with single-use, hashed tokens, in templated HTML emails with a text
    fallback, delivered through an outbox with retries. Account deletion and data export for GDPR/KVKK.
  </Card>
  <Card title="Abuse protection" icon="warning">
    Login lockout per IP and account, a per-IP API rate limit shared through Redis, CSP and other security
    headers, and an audit log of every security event.
  </Card>
  <Card title="Standard HTTP" icon="seti:json">
    Versioned `/api/v1` URLs, correct status codes and RFC 9457 problem details for every error.
  </Card>
  <Card title="Observability" icon="seti:graphql">
    Prometheus metrics with ready alert rules and a Grafana dashboard, OpenTelemetry tracing, trace ids in logs
    and the `X-Trace-Id` header, JSON logs in prod.
  </Card>
  <Card title="Quality gates" icon="approve-check">
    Testcontainers, ArchUnit and k6 tests, Trivy scan, signed multi-arch images with SBOM, pinned dependencies,
    Kubernetes manifests, strict Javadoc documentation.
  </Card>
</CardGrid>
